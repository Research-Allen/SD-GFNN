# Software Requirements

## Core Packages

- Python >= 3.10
- PyTorch >= 2.0
- NumPy >= 1.24
- Pandas >= 2.0
- SciPy >= 1.11
- Scikit-learn >= 1.3
- Matplotlib >= 3.7

Install via:

```bash
pip install -r requirements.txt
```

## Determinism

Random seeds are provided in:

seeds/random_seeds.txt

To reproduce published results, use the supplied seeds.
